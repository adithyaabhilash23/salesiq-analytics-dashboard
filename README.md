# SalesIQ Analytics Dashboard

A modern and interactive Sales Analytics Dashboard built using pure HTML, CSS, JavaScript, and Chart.js.

This project provides a clean business intelligence interface for tracking product sales, revenue trends, category performance, regional analytics, and KPI metrics in real time.

---

## 🚀 Features

- 📊 Dynamic Sales Analytics Dashboard
- 📈 Revenue Trend Visualization
- 🥧 Category-wise Revenue Breakdown
- 📦 Product Performance Tracking
- 🌍 Regional Revenue Analytics
- 💾 CSV Export Functionality
- ⚡ Real-time Dashboard Updates
- 🎨 Modern SaaS-style UI Design
- 📱 Fully Responsive Layout
- 🔥 Interactive Charts using Chart.js

---

## 🛠 Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js
